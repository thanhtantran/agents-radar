### 1. **Claude Code Ecosystem đang bùng nổ**
- 4/10 repo trending liên quan trực tiếp đến Claude Code

- Xu hướng: Từ sử dụng đơn thuần → tối ưu hóa workflow → tự động hóa hoàn toàn

### 2. **Knowledge Graph cho Code Intelligence**
- GitNexus (+1,102⭐) đại diện cho xu hướng mới: zero-server, client-side knowledge graph
- Graph RAG đang trở thành standard cho code exploration
- Tín hiệu: Developers muốn hiểu codebase nhanh hơn mà không cần server infrastructure

### 3. **AI Agents đang "nhẹ hóa"**
- nanobot (41K⭐) - "ultra-lightweight"
- CowAgent (43K⭐) - "nhẹ hơn OpenClaw"
- tinyagentos (90⭐) - "low-cost consumer hardware"
- Xu hướng: Từ cloud-heavy → edge-first → consumer hardware

### 4. **Embedded AI trên NPU Rockchip đang tăng tốc**
- Nhiều projects mới cho RK3588 NPU (InternVL3.5, YOLO11 conversion)
- Integration với Kubernetes (Talos Linux extension)
- Tín hiệu: Edge AI đang chuyển từ prototype → production-ready

### 5. **MCP (Model Context Protocol) đang trở thành standard**
- activepieces có ~400 MCP servers
- OpenCLI chuẩn hóa tool access qua AGENT.md
- Xu hướng: Từ custom integrations → standardized protocols

### 6. **Memory & Context Management là bài toán lớn**
- beads (+498⭐) - memory upgrade
- claude-mem (68K⭐) - auto capture context
- taosmd (23⭐) - local-first AI memory
- Tín hiệu: Long-running agents cần persistent, efficient memory
