## 3. Phân tích tín hiệu xu hướng

### Agent Harness Optimization Wave
Claude Code, Codex, Cursor đang có ecosystem riêng tools tối ưu performance. **ECC** (289K ⭐), **hallmark** (+2244), **andrej-karpathy-skills** (+638) cho thấy cộng đồng focus vào skills, instincts, memory, security. Pattern này giống như early days của IDE extensions.

### Security-First Agent Development
**NVIDIA/SkillSpector** (+214) scan skills trước khi install - signal rõ: supply-chain risks trong AI agents đang được coi trọng. Giống dependency scanning nhưng cho agent skills.

### Context Compression & Memory
**thedotmack/claude-mem** (103K ⭐) persistent context across sessions, **headroomlabs-ai/headroom** (77K ⭐) compress tool outputs 20-95% - addressing context window constraints. Agents cần memory dài hạn và efficient context.

### Embedded AI Acceleration
Rockchip NPU (RK3588/RK3576) có momentum mạnh:
- **Rust-based inference engines** mới (open_rknpu2_lm_infer, rktop)
- **Full stack solutions** từ kernel drivers (rk3588-rknn-core) đến deployment toolchains (Edge_ModelDeploy)
- **Offline-first edge agents** (taOS, taosmd) run trên consumer hardware (Orange/Raspberry Pi, mini PCs)
- **Embodied AI** (DuckBuddy) - NPU-powered robots

Edge AI không còn là prototype - production-ready với proper tooling (Docker, Terraform, Qt studios, multi-core concurrency, devfreq governors).

### Vertical AI Applications
Specialized apps thay vì general chatbots:
- **Trading agents** (TauricResearch/TradingAgents +1395, ZhuLinsen/daily_stock_analysis 67K)
- **Voice synthesis** (debpalash/VoiceStudio +2297 fully-local 646 languages)
- **Design automation** (alchaincyf/huashu-design +251 HTML-native cho agents)
- **Career automation** (career-ops-hq/career-ops 77K job search agent)

Mỗi vertical có constraints riêng, agents specialized hoạt động tốt hơn general assistants.
