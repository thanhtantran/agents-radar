# Báo cáo Xu hướng AI Mã nguồn mở - 28/08/2026

## 📊 Tóm tắt hôm nay

Hôm nay chứng kiến một làn sóng mạnh mẽ về **Agent Skills và Agent Harness** - các hệ thống trang bị năng lực cho AI agents. Cộng đồng đang chuyển từ việc xây dựng agents đơn lẻ sang việc tạo ra các thư viện kỹ năng có thể tái sử dụng và các hệ thống tối ưu hiệu suất agent. 

Điểm nổi bật là sự bùng nổ của các dự án tập trung vào **edge AI với Rockchip NPU** (RK3588/RK3576), đặc biệt là các giải pháp chạy LLM trên Orange Pi. Xu hướng "local-first AI" đang được đẩy mạnh với các hệ thống self-hosted, offline-capable.

Một pattern mới xuất hiện: **AI agents tích hợp sâu vào developer workflow**, từ code generation, architecture diagrams, đến video production và knowledge management.

## 🔥 Phân tích Tín hiệu Xu hướng

### 1. **Agent Skills Economy đang hình thành**
Cộng đồng không còn viết agents từ đầu mà đang xây dựng các thư viện kỹ năng có thể kết hợp:
- Scientific skills (K-Dense-AI)
- Architecture diagrams (archify)
- Video production (OpenMontage)
- Knowledge management (claude-obsidian)

**Pattern**: Agents sẽ trở thành platform, skills là "apps"

### 2. **Local-First AI Infrastructure đang bùng nổ**
Phản ứng với privacy concerns và chi phí cloud:
- Self-hosted OS (taOS)
- Offline memory (taosmd, claude-mem)
- Edge inference (RKLLM, RKNPU)
- Consumer hardware clustering (taOS auto-clustering)

**Tín hiệu**: Users muốn "own their intelligence" thay vì thuê

### 3. **Rockchip NPU đang trở thành standard cho edge AI**
RK3588/RK3576 xuất hiện trong 10+ repos:
- RKLLM cho LLM inference
- RKNPU cho vision models
- Orange Pi là hardware phổ biến nhất
- Mainline kernel support đang được phát triển (rocket driver)

**Breakthrough**: Giá $50-150 có thể chạy multimodal AI locally

### 4. **Agent Harness Performance Optimization**
ECC (244K stars) đặt ra trend mới:
- Skills management
- Memory optimization
- Security guardrails
- Research-first development

**Pattern**: Shift từ "make it work" sang "make it work well"

### 5. **AI-Native Professional Tools**
Thay thế tools truyền thống:
- Career management (career-ops)
- Stock analysis (daily_stock_analysis)
- PowerPoint creation (ppt-master)
- Video editing (OpenMontage, OpenCut)

**Tín hiệu**: Mọi vertical đều có thể được "agentified"

### 6. **Compression & Efficiency**
Token cost đang trở thành bottleneck:
- headroom: 20-95% token reduction
- claude-mem: Context compression
- Graph-based approach (graphify) thay vì vector

**Pattern**: Optimize context window trước khi optimize model

### 7. **Cross-Platform Agent Ecosystem**
Repos nhắm đến multiple platforms:
- Claude Code, Codex, Cursor, Gemini CLI, Hermes
- MCP (Model Context Protocol) xuất hiện nhiều
- Unified APIs (RKLLM-API-Server với OpenAI compatibility)

**Tín hiệu**: Fragmentation đang giảm, interoperability tăng
