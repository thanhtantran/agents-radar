## 3. 🔥 Tín hiệu xu hướng

### **Agent orchestration mainstream**
Google `ax` entry = big validation. Agent framework no longer experiment. Production-grade orchestration infra emerge.

### **Memory persistence battle**
3+ major memory solution (claude-mem, taosmd, mem0ai). Agent lose context across session = solved problem now. Memory layer become standard component.

### **Token economy critical**
Multiple compression solution (headroom, caveman). Token cost real pain point. 20-65% reduction = competitive advantage. Efficiency over raw capability.

### **Edge AI production ready**
RK3588 NPU ecosystem mature. Kubernetes driver, DKMS package, FFI binding, zero-copy pipeline. Edge LLM inference no longer hobby project. Real deployment.

### **Office suite as agent runtime**
Univer pattern = interesting. Not "AI feature in office". Entire office suite become agent execution environment. Doc/spreadsheet/slide = agent workspace.

### **Multi-agent vertical solution**
Stock trading, job search, video edit, PPT generation. Not general agent. Domain-specific multi-agent system. Pattern: multi-agent + domain knowledge + automation workflow.

### **Local-first movement strong**
taOS, anything-llm, open-webui, nouride. Own intelligence, not rent. Offline-first architecture. Privacy + control priority. Self-hosted agent OS emerge.

### **Rust in AI infrastructure**
Codewhale, astra_lite, rkllm-rs, RockNPU. Rust claim AI infra territory. Performance + safety = compelling for agent runtime + edge AI.

### **Knowledge graph over vector store**
Graphify pattern: deterministic AST parse, every edge explain, queryable. No vector store ambiguity. Structured knowledge graph win for codebase understanding.

### **Agent harness performance engineering**
ECC (+265k ⭐) = meta-trend. Not agent itself. Agent performance optimization system. Skill, instinct, memory, security. Agent need management layer.
